# 2026 CAPSTONE

Unreal Engine 5.4 기반의 3D 로그라이크 게임 프로젝트입니다. 시드 기반으로 던전을 생성하고, 방 단위 전투와 보상·상점·보스방을 거쳐 다음 스테이지로 진행합니다. 플레이 기록을 분석해 플레이 성향을 추정하고, 이를 전투 구성에 활용하는 것을 프로젝트 연구 주제로 삼고 있습니다.

## 주요 기능

### 절차적 맵 생성

- 입력 시드를 사용하는 재현 가능한 방 배치
- 후보 위치의 연결 상태를 평가하는 가중치 기반 확장
- 2×2 방 밀집 구조를 억제하고 분기 경로를 구성
- 막다른 방을 보상방과 상점으로 활용하고, 시작방에서 떨어진 위치에 보스방 배치

### 방 단위 전투

- 데이터 에셋에서 방 유형별 몬스터 풀, 스폰 점수, 몬스터 비용·가중치·출현 수를 설정
- 몬스터 풀과 점수 예산에 따라 방별 전투 구성을 선택
- 최근 방에서 사용한 몬스터의 재등장 가중치를 낮춰 구성이 반복되는 현상 완화
- 생존 몬스터 수 또는 전투 경과 시간에 따라 증원하고, 예고 효과와 등장 연출 적용
- 보스방 클리어 후 출구 포탈 활성화

### 플레이 행동 분석

- 플레이 시간, 방문 구역, 몬스터 처치율, 근접 처치 비율, 장애물 통과율을 수집
- 플레이 데이터가 일정량 쌓이면 K-Means로 성향 군집화
- 전투 성향을 몬스터 스폰 점수에 반영하고, 탐험 성향에 따라 방 안의 몬스터 배치 위치를 조정
- 학습 데이터와 결과를 저장하며, 초기 데이터가 부족할 때는 중립값으로 시작

### 스테이지 진행 및 UI

- 스테이지 데이터 에셋에서 방 개수, 시드 방식, 몬스터 스폰 규칙을 설정
- 보스방 포탈 진입 후 로딩 화면을 거쳐 다음 스테이지 생성
- 미니맵은 `TestMap`에서만 표시

## 기술 스택

- Unreal Engine 5.4
- C++ / Blueprint
- Gameplay Ability System (GAS)
- Enhanced Input, UMG, Niagara

## 실행

1. Unreal Engine 5.4에서 `P_CAP.uproject`를 엽니다.
2. 기본 시작 레벨은 `VillageMap`입니다.
3. 맵 생성과 미니맵을 확인하려면 에디터에서 `Content/_Workspace/Maps/TestMap`을 엽니다.
4. 에디터에서 Play를 눌러 실행합니다.

`TestMap`에서 `R`은 새 랜덤 시드로 맵을 다시 생성하고, `T`는 현재 시드를 재사용해 다시 생성합니다. 미니맵은 `Z`를 누르는 동안 확대됩니다.

## 주요 코드 위치

| 경로 | 역할 |

| `Source/P_CAP/Private/AI/` | 플레이 기록 추적과 성향 분석 |
